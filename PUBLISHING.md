# Public distribution options

Recommended primary distribution:

1. Public GitHub repository for source, issues and releases.
2. GitHub Pages for the p2 update-site URL.
3. GitHub Releases for downloadable update-site ZIP files.

Optional after the public p2 URL is stable:

- Submit the extension to Eclipse Marketplace.
- Ask the DBeaver project to reference the extension in its third-party extension documentation if they consider it appropriate.

The project should be described as an independent third-party extension. Do not imply that it is an official DBeaver component.
